description: "Learn how many requests you can send to the Acme API each minute."
---

The Acme API limits how many requests you can send each minute.

## Rate limits

| Limit | Value |
| --- | --- |
| Requests per minute | 120 |
| Wait time after exceeding the limit | 60 seconds |

If you send more than 120 requests in a minute, wait 60 seconds before you send more requests.
